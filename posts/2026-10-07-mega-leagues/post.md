Title: Mega Edition leagues: best cores and the Mega to run with them (pick3 sims)

Only posting the Mega recommendations this time, because hey, it's Mega league and everyone wants to use a Mega. The same old meta is still behind these numbers, so if you'd rather stick with what you know, those teams still hold up. PvPoke did update some of its Mega league rankings on Oct 1, and that shifted a few things up.

Every team below runs one Mega. Each row is a core (keep both Pokémon) plus the slot that completes the team, ranked by projected strength against that league's meta. The options under a core are close, so pick whichever you own or like. Every link opens the full team analysis on [pick3.gg](https://pick3.gg), run against your own Pokémon if you have imported them.
