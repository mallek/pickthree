About
Where these numbers come from
Every number on this site is built from real GO Battle League battles that pick3 users chose to share. Nothing is scraped, estimated or simulated.
What one shared battle contains
✓League and season
✓When the battle happened
✓The reporter's three Pokémon and the moves they had set
✓Which opponent Pokémon were seen
✓Win or loss
✓Rank band (Below Ace, Ace, Veteran, Expert, Legend)
✓A random device id, so we can count contributors without knowing who they are
Never collected
✕Your Pokémon collection or storage
✕IVs, levels or CP
✕Trainer names, friend codes, emails or anything that identifies you
✕Location
How to contribute
Log your battles in the pick3 app. Sharing is on by default, so every battle you log shows up here within about 10 minutes. To stop sharing, switch it off in Settings → Share battles. Battles already shared stay in the counts.

For other apps
API
Any battle logger can post records here with an API key. Records use the same fields listed above, are tagged with the source app, and count toward the same totals. Keys are free; abusive or fabricated data gets a key revoked.
POST https://meta.pick3.gg/api/v1/battles
Authorization: Bearer <your key>
