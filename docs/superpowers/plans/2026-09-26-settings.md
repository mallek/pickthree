# Settings (Piece 4, round 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the Settings sheet as a hub with four pages (Your data, Community, Appearance,
About) on the ui `Sheet`, put every Settings confirm through `ConfirmSheet`, retire the rank band
(no control, `band: null` on every record sent), and write the Settings audit record for Travis to
sign.

**Architecture:** One new ui component (`Switch`, the labeled on/off row every page uses) lands
first with its gallery entry. The rank band is retired in `metaShare.ts` and the store next, a
data change with its own tests. Then `apps/web/src/screens/Sheet.tsx` is replaced by a
`screens/settings/` folder: the hub is the ui `Sheet`'s root page and each row pushes a page
component that reads the store itself. Captures, the enforced audit and the record last.

**Tech Stack:** React 19, TypeScript 5.9 strict, vitest 4 + jsdom + Testing Library,
puppeteer-core audit scripts.

**Spec:** `docs/superpowers/specs/2026-09-26-design-rest-of-app-design.md` (sections "Decisions",
"App-wide rules applied here", "Settings", "States", "Testing", "Records and sign-off",
"Cleanup"). Foundation: `docs/superpowers/specs/2026-09-24-design-foundation-design.md`. Record
models: `docs/design/audits/teams.md`, `your-meta.md` (signed).

## Global Constraints

- Exact pinned versions; braces on all control flow; no em dashes anywhere (code, docs, commit
  messages); "Pokémon" with the accent in UI copy ("Poke Genie" keeps its own spelling); American
  spelling ("colored").
- Tokens only (`npm run check-colors`); no class another screen already styles (grep
  `apps/web/src/app.css` and `packages/ui/base.css` first); 44px touch targets.
- Red only for destroying data: Forget and turning sharing off are `danger`; Start fresh deletes
  nothing and is `default` (violet). The sharing-off warning line under the switch is neutral text.
- Pink only for measured data: nothing in Settings is measured, so no pink.
- The collection never leaves the device. No new outbound call; retiring the band only removes a
  field's value from records already sent by the existing path.
- Copy is the spec's, verbatim, where the spec gives it (titles, lines, confirm labels).
- Stage explicit paths; commit messages: subject alone on line 1, a blank line, body, trailers;
  write the message to a file and `git commit -F`. Never kill a process you did not start.

1. **`Switch` is a ui component** (`packages/ui/src/components/Switch.tsx`): Settings has three,
   and the Collection Filters sheet and the detail page (round 2) need the same row. A button with
   `role="switch"` and `aria-checked`, the label and an optional line on the left, the track on
   the right. [New shared component; its look matches today's `.toggle`/`.switch`.]
2. **The hub rows stay in the app** (`SettingsRow` in `screens/settings/SettingsRow.tsx`): only
   Settings uses a drill-in row. [Not in ui until a second screen needs it.]
3. **Forget uses `Button variant="danger"`**, the ui's one destructive style, rather than a
   hand-styled red text button. [Look.]
4. **The Import card's button is the hub's one primary `Button`.** [One primary per screen.]
5. **"N battles" on the Your data row counts every league's sets** (`storage.loadAllSets()`, read
   again whenever `s.sets` changes, as Your Meta's contribution line does). [Definition.]
6. **Capture names:** `settings-hub`, `settings-hub-no-collection`, `settings-your-data`,
   `settings-log-imported`, `settings-community`, `settings-community-sent`,
   `settings-appearance`, `settings-about`, `settings-about-leaves`, `settings-confirm-forget`,
   `settings-confirm-fresh`, `settings-confirm-sharing`. `06-sheet` and
   `08d-leagues-sheet-in-settings` go (the league switcher leaves Settings); the layering check
   that 08d made moves to `settings-confirm-forget` (the confirm must paint over the Settings
   sheet). [Names.]
7. **The stored `settings.share.band` stays in the `Settings` type**, documented as retired and
   ignored. [No migration.]

## Review Focus

1. **A switch flipped on a pushed page:** the page shows the new state at once, and the hub's
   summary line shows it after back (the pushed page must read the store, not a value captured at
   push time).
2. **Cancel on each confirm:** nothing changes (sharing stays on, the log stays in its season, the
   collection stays), and focus returns inside the Settings sheet.
3. **Escape with a confirm open over Settings:** closes only the confirm, not the sheet.
4. **A band stored by an older version:** records still go out with `band: null`.
5. **Settings with no collection:** the hub shows "Import a CSV", no Forget, and Your data reads
   "No collection yet" with the Import card; nothing throws on `s.collection === null`.

- [ ] **Step 3: Implement**

```tsx
/** A labeled on/off row: the label (and an optional one-line explanation) on the left, the
 * track on the right, the whole row one 44px+ button. Controlled: a tap asks `onChange` for the
 * opposite state and the parent decides, so a confirm can stand between the tap and the change. */
export function Switch({
  label,
  line,
  checked,
  onChange,
  disabled,
}: {
  label: string;
  line?: string;
  checked: boolean;
  onChange: (next: boolean) => void;
  disabled?: boolean;
}) {
  return (
    <button
      type="button"
      role="switch"
      aria-checked={checked}
      className="ui-switch-row"
      disabled={disabled}
      onClick={() => onChange(!checked)}
    >
      <span className="ui-switch-text">
        <span className="ui-switch-label">{label}</span>
        {line ? <span className="ui-switch-line">{line}</span> : null}
      </span>
      <span className={`ui-switch${checked ? ' on' : ''}`} aria-hidden="true" />
    </button>
  );
}
```

  CSS in `base.css`, tokens only, modeled on `apps/web/src/app.css`'s `.toggle` and `.switch`
  (44x26 track, 20px thumb, `--accent` when on, `--surface2` and `--divider` when off; label at
  15px, line at `--fs-support` in `--muted`; min-height 52px; a visible `:focus-visible` ring;
  `disabled` at reduced opacity). Export from `index.ts`. Gallery: a `Switch` section with one on,
  one off with a line, one disabled.
